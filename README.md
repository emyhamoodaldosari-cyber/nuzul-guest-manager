# نُزل — إدارة الاستراحة ومعلومية النزلاء

تطبيق Android عربي مبني بـ React Native وExpo وTypeScript. يعمل محليًا دون خادم أو اشتراك، ويسجل بيانات النزيل مرة واحدة مع إقامات مستقلة عند كل عودة.

## ما تم تنفيذه

- لوحة متابعة للمقيمين والغرف المشغولة والفارغة.
- تسجيل النزيل، البحث بالاسم أو الهوية، تعديل البيانات، وسجل الإقامات.
- تسجيل المغادرة والعودة، نقل الغرف مع حفظ سجل النقل، وتعديل ملاحظات الإقامة.
- غرف متعددة النزلاء مع سعة محددة ومنع تجاوزها.
- مراجعة معلومية جميع الموجودين، إصدار لقطة ثابتة، أرشيف، وتوليد PDF عربي أفقي ومشاركته من Android.
- إعدادات المنشأة والترويسة والجهة المستلمة والخطاب والمدير ومعد البيانات.
- قاعدة SQLite مشفرة باستخدام SQLCipher ومفتاح عشوائي في SecureStore.
- قفل ببصمة الهاتف أو رمز قفله، إخفاء الشاشات والنوافذ عند الانتقال للخلفية، ومنع التقاط الشاشة.
- تصدير نسخة مشفرة بكلمة مرور واستعادتها على تثبيت فارغ، دون استبدال بيانات موجودة.

لا توجد بيانات نزلاء حقيقية مضمنة، ولا تُرفع بياناتك إلى خادم. أسماء المنشأة والعنوان المبدئية مستمدة من النموذج المرفق وتحتاج مراجعة في الإعدادات. ملف `docs/sample-report.pdf` يحتوي بيانات اصطناعية فقط.

## حالة الإصدار

هذه نسخة MVP أولى مكتملة المسارات الأساسية في الشيفرة، وليست إصدارًا تم اختباره ميدانيًا. نجح فحص TypeScript واختبارات SQLite والمنطق والنسخ الاحتياطي، وتصدير حزمة JavaScript/Hermes لأندرويد، وتوليد المشروع الأصلي عبر Expo prebuild. لم يُبنَ APK في هذه البيئة، ولم تُختبر SQLCipher والبصمة والطباعة والمشاركة على هاتف فعلي. قائمة اختبار الهاتف في `docs/DEVICE-QA.md`.

## التشغيل والتطوير

يلزم Node.js 24 وnpm. داخل هذا المجلد:

```bash
npm ci
npm run check
```

**لا تستخدم Expo Go**: قاعدة البيانات المشفرة تحتاج بناء Android مخصصًا، ويتوقف التطبيق إذا لم يجد SQLCipher.

على جهاز تطوير يحتوي Android SDK وJDK المناسبين:

```bash
npm run android
```

ثم لتشغيل Metro في جلسات التطوير:

```bash
npm start
```

## إخراج APK من Codespaces أو جهاز لا يحتوي Android SDK

بعد تسجيل الدخول إلى حساب Expo الخاص بك، اربط المشروع بحسابك ثم شغّل بناء APK:

```bash
npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest build --platform android --profile preview
```

`preview` ينتج APK داخليًا قابلًا للتثبيت. يتطلب البناء اتصالًا بالإنترنت وحساب Expo، وقد يخضع لتوفر وحدود خدمة البناء. لم تُربط الشيفرة بأي حساب أو مشروع خارجي.

بعد تثبيت APK، فعّل قفل شاشة أندرويد برمز أو بصمة. افتح التطبيق، راجع بيانات المنشأة، أضف الغرف وسعتها، ثم سجّل النزلاء واحدًا واحدًا. لا تُدخل بيانات حقيقية قبل اجتياز قائمة اختبار الهاتف.

## قاعدة التقرير

يشمل الكشف **كل إقامة مفتوحة وقت الإصدار**، مهما كان تاريخ الدخول. من غادر قبل الإصدار لا يظهر. بعد النقل تظهر الغرفة الحالية. النزيل العائد يحصل على إقامة جديدة مرتبطة بسجله القديم. كل شخص له صف مستقل وعدد الأفراد في صفه واحد؛ لا تخفِ أسماء المرافقين داخل عداد جماعي.

المعاينة ليست إصدارًا. عند الضغط على الإصدار تُقرأ البيانات داخل معاملة واحدة وتُقارن بالمعاينة؛ إن تغيرت بيانات النزلاء أو الغرف أو إعدادات التقرير، تُرفض العملية حتى تحديث المعاينة. يُحفظ محتوى التقرير كاملًا داخل القاعدة المشفرة، وتمنع مشغلات قاعدة البيانات تعديل التقرير أو حذفه. لا تتغير النسخ القديمة بعد تعديل البيانات.

جميع الأوقات مخزنة بصيغة UTC موحدة، وتُعرض بتوقيت اليمن `Asia/Aden`. إدخال وقت القدوم يدعم تاريخًا سابقًا صحيحًا بصيغة `YYYY-MM-DD HH:mm`، ويمنع المستقبل أو التداخل مع إقامة سابقة.

## الهوية والبيانات الناقصة

تُحفظ أرقام الهوية كنصوص مع الأصفار في بدايتها، وتُوحّد الأرقام العربية والفارسية. يمنع تكرار الرقم مع نوع الهوية نفسه. يمكن حفظ نزيل ناقص بعض بيانات الهوية لتسجيل الواقع، لكن التطبيق ينبه قبل الإصدار ويطلب تأكيدًا إضافيًا، ويكتب «غير مسجل» في الحقول الناقصة.

نص الخطاب الحالي يعكس قرارك بأن الكشف يشمل جميع الموجودين. يمكن تعديله من الإعدادات، واستخدام `{date}` لإضافة التاريخ. القالب يستخدم حقول وترتيب نموذج Word مع إخراج جديد واضح؛ ليس نسخة مطابقة بكسلًا ببكسل ولا إثباتًا لاعتماد الجهة المستلمة له. Word وتوقيع رقمي وإرسال تلقائي ليست ضمن هذه النسخة.

## النسخ الاحتياطي

من الإعدادات اختر تصدير نسخة مشفرة، وحدد كلمة مرور من 12 حرفًا على الأقل. احفظ الملف وكلمة المرور في مكانين منفصلين. التشفير AES-256-GCM مع ملح وnonce عشوائيين ومفتاح مشتق بواسطة PBKDF2-HMAC-SHA256 بعدد 600,000 دورة. أي كلمة مرور خاطئة أو تعديل في المحتوى يؤدي إلى رفض فك التشفير.

النسخة تحفظ الغرف والنزلاء والإقامات وحركة الغرف والكشوف والإعدادات. للاستعادة على هاتف آخر، ثبّت التطبيق وافتحه ثم استعد النسخة **قبل إضافة أي غرفة أو نزيل**. يُتحقق من البنية والعلاقات والسعة داخل معاملة، وتُلغى العملية كاملة عند الخطأ. الحد المبدئي لمحتوى النسخة غير المشفر 16 MB، والملف المشفر نحو 33 MB.

حذف التطبيق أو مسح بياناته يفقد القاعدة ومفتاحها المحلي؛ يلزم ملف النسخة وكلمة مروره للاستعادة. النسخ التلقائي لأندرويد معطّل لتجنب نقل قاعدة لا يتوفر مفتاحها. لا توجد آلية لاسترجاع كلمة مرور منسية.

ملف PDF المشارك غير مشفر بطبيعته ليمكن فتحه لدى المستلم. ينشأ مؤقتًا في ذاكرة التطبيق المؤقتة ويحذف بعد رجوع نافذة المشاركة؛ نسخة المستلم خارج تحكم التطبيق. إذا انتهت عملية التطبيق فجأة أثناء المشاركة، قد يبقى الملف المؤقت حتى تنظيفه في التشغيل التالي.

## بنية المشروع

| المسار           | المسؤولية                                        |
| ---------------- | ------------------------------------------------ |
| `App.tsx`        | القفل والتنقل ودورة حياة الواجهات                |
| `src/screens`    | الرئيسية والنزلاء والغرف والكشوف والإعدادات      |
| `src/components` | مكونات عربية مشتركة وحالة البيانات               |
| `src/domain`     | الأنواع والتحقق والتواريخ                        |
| `src/database`   | المخطط والمعاملات وطبقة البيانات والاتصال المشفر |
| `src/reports`    | القالب العربي والتصدير إلى PDF                   |
| `src/security`   | تشفير النسخ والاستعادة واختيار الملفات           |
| `tests`          | اختبارات تستخدم SQLite حقيقية ببيانات اصطناعية   |

تُسلسل جميع عمليات القاعدة، بما فيها القراءات، عبر اتصال واحد. هذا يمنع إدخال عملية غير مقصودة في معاملة أخرى ويحافظ على إعدادات مفتاح التشفير والمفاتيح الخارجية. كل الاستعلامات ذات البيانات تستخدم معاملات مربوطة. لا يوجد جمع بيانات أو خدمة تحليلات ضمن منطق التطبيق.

## التحقق

```bash
npm run check
npx expo export --platform android --output-dir dist
npx expo prebuild --platform android --no-install
```

الاختبارات تشمل الاستمرار من أيام سابقة، المغادرة، العودة، النقل، تجاوز السعة، التسجيل المتزامن، التكرار، ثبات اللقطات، المعاينة القديمة، Unicode والأصفار، تواريخ غير صالحة، SQL/HTML injection، استعادة النسخ وتلفها وكلمة المرور الخاطئة.

لمراجعة نموذج التقرير الاصطناعي في المتصفح افتح `docs/sample-report.html`. نسخة PDF المرفقة مولدة للمراجعة بمحرك HTML مكتبي؛ يجب اعتماد نتيجة Android الفعلية بعد اختبارها.

## بناء APK باستخدام GitHub Actions دون حساب Expo

يحتوي المشروع على `.github/workflows/android-apk.yml`، وهو مسار بناء يدوي لم يُنفذ في هذه البيئة:

1. ارفع **محتويات** مجلد `nuzul-app` إلى جذر مستودع GitHub، بما فيها مجلد `.github`.
2. افتح المستودع ثم **Actions → Build Android preview APK → Run workflow**.
3. بعد نجاح البناء، افتح التشغيل وحمّل **nuzul-android-preview** من **Artifacts**.
4. فك ضغط ملف التحميل للوصول إلى APK وتثبيته على الهاتف.

هذا المسار يجهز Android SDK وNDK، ويفحص المشروع، ويولد Android مع SQLCipher، ثم يبني APK مستقلًا لا يحتاج Metro. يستهدف `arm64-v8a` للهواتف الحديثة. مفتاح توقيعه هو المفتاح التجريبي الافتراضي في قالب Android؛ خُصص للاختبار الداخلي، ويحتاج توقيعًا خاصًا ثابتًا قبل اعتماد إصدار توزيع. لم يُرفع المشروع إلى أي مستودع ولم يُشغّل المسار على حسابك.

يحتوي `.github/workflows/checks.yml` على فحوص الشيفرة والاختبارات عند استخدام المستودع. صفحة المتابعة الفعلية للبناء هي GitHub Actions؛ لا يوجد ادعاء بأن APK قد تم إنتاجه داخل هذا الملف المضغوط.

## إعادة إنشاء المجلد المضغوط

على Codespaces أو Linux الذي يحتوي Python 3:

```bash
npm run package
```

ينشئ الأمر ملف `Nuzul_Android_v0.2.0.zip` بجانب مجلد المشروع، ويضم الشيفرة والأصول والوثائق وملفات الاختبار والبناء فقط. لا يضم `node_modules` أو ملفات الجهاز أو مجلدات البناء الأصلية أو بيانات اعتماد.
