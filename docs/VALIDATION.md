تشمل الاختبارات إدارة الإقامة والتقرير الثابت، المعاملات المتزامنة، الهوية والأصفار والبحث العربي، دفعات الغرف وتراجعها، منع حذف الغرف ذات التاريخ، ترتيب الغرف، حركة اليوم بمنتصف الليل اليمني، سجل النقل، فلاتر فترات التقرير، أسماء الملفات، النسخ المشفر ذهابًا وإيابًا، كلمة المرور الخاطئة والتلاعب، رفض التداخل والفجوات في سجلات النسخ، والملاحظات الطويلة في الكشوف القديمة.

اختبارات التشفير في Node تخص ملفات النسخ الاحتياطية. لا تختبر تكامل SQLCipher الأصلي أو Android Keystore أو نظام البصمة. معاينة واجهة الإصدار الأول كانت مكتبية من مكونات React Native Web؛ لم تُنفذ مراجعة بصرية أصلية لشاشات 0.2.0 على هاتف. نموذج PDF المكتبي يستعمل قالب HTML نفسه بمحرك WeasyPrint؛ يلزم اعتماد ناتج Android الفعلي بعد الاختبار.

المشروع لا يتضمن بيانات نزلاء حقيقية، ولا APK جاهزًا، ولا ادعاء باعتماد نموذج التقرير رسميًا. مسار بناء GitHub Actions هو إعداد قابل للتشغيل من حساب صاحب المستودع، وليس نتيجة بناء مكتملة.
