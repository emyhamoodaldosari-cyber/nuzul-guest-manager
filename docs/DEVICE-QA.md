# اختبار القبول على هاتف Android

هذا الملف قائمة تحقق لاختبارات لم تُنفذ على هاتف ضمن بيئة إنشاء المشروع. استخدم بيانات اصطناعية في البداية.

## البناء والقفل

- [ ] بناء APK بملف `preview` وتثبيته وفتح التطبيق.
- [ ] لا يفتح السجل عند إلغاء المصادقة أو فشلها.
- [ ] يعمل فتح القفل ببصمة قوية وبالرجوع لرمز قفل الهاتف.
- [ ] يظهر توجيه واضح عندما لا يكون قفل الهاتف مفعّلًا.
- [ ] التأكد من عمل SQLCipher فعلًا ومن رفض أي نسخة بدون التشفير.
- [ ] الخلفية ومبدل التطبيقات لا يكشفان بيانات أو نوافذ النزيل.
- [ ] العودة من مشاركة PDF أو اختيار نسخة احتياطية تطلب فتح القفل وتحافظ على العملية.

## الشاشات والبيانات

- [ ] مراجعة العربية على هاتف عربي وهاتف إنجليزي، وعرض 360 و412 نقطة.
- [ ] تجربة لوحة المفاتيح، التمرير، تكبير خط النظام، وزر الرجوع.
- [ ] إضافة غرفتين بسعات مختلفة، وتعديل اسم غرفة وسعتها.
- [ ] تسجيل نزيل، إغلاق التطبيق إغلاقًا كاملًا، وفتحه للتأكد من الحفظ.
- [ ] منع تكرار الهوية ومنع إشغال يتجاوز السعة.
- [ ] تسجيل نزيلين في غرفة واحدة ثم نقل أحدهما وتسجيل مغادرته وعودته.
- [ ] البحث بالهوية ذات الأصفار، وتعديل بيانات النزيل وملاحظاته.

## التقرير

- [ ] فحص تقرير 1 و11 و26 نزيلًا، وبأسماء وملاحظات طويلة.
- [ ] مراجعة تطابق جميع الحقول مع السجل دون قص أو تداخل أو انعكاس أرقام الهوية.
- [ ] مراجعة وقت وتاريخ القدوم والإصدار بتوقيت اليمن.
- [ ] التحذير من الهوية الناقصة، وتأكيد المراجعة قبل الإصدار.
- [ ] رفض المعاينة القديمة بعد تعديل بياناتها.
- [ ] فتح PDF الناتج على الهاتف وإرساله تجريبيًا إلى وجهة تختارها بنفسك.
- [ ] إصدار كشف، تعديل البيانات وتسجيل مغادرة، ثم إعادة تصدير الكشف القديم ومقارنة محتواه.
- [ ] مراجعة الترويسة والخطاب مع النموذج الذي تعتمدونه لدى الجهة المستلمة.

## النسخ والاستعادة

- [ ] تصدير نسخة مشفرة، وحفظها إلى وجهة تختارها.
- [ ] رفض كلمة مرور خاطئة وملف تالف أو غير مدعوم.
- [ ] استعادة النسخة على تثبيت فارغ آخر، ومقارنة الغرف والنزلاء وحركة الإقامة والكشوف.
- [ ] رفض الاستعادة إذا كانت توجد بيانات حالية.
- [ ] إلغاء اختيار ملف وإلغاء نافذة المشاركة، ثم فتح التطبيق وإعادة المحاولة.

لا يُعد نجاح اختبارات Node أو تصدير حزمة Android بديلًا عن هذه الخطوات الأصلية على الهاتف.

## قبول إضافات الإصدار 0.2.0

- [ ] إضافة غرف 101 إلى 110 بسعة موحدة، ثم تجربة نطاق يتداخل معها والتأكد من عدم الإضافة الجزئية.
- [ ] التأكد من ترتيب 8 و9 و10 و11، وتوحيد كتابة ١٠١ و101.
- [ ] حذف غرفة غير مستخدمة، ومنع حذف غرفة غادرها النزيل أو انتقل منها.
- [ ] البحث عن اسم مشكول بصيغة بلا تشكيل وعن الهوية بأرقام عربية وعن الغرفة الحالية.
- [ ] عرض حركة الغرف عند نقلين متتاليين وعند عودة النزيل بإقامة جديدة.
- [ ] مراجعة دخول ومغادرة اليوم قرب منتصف الليل اليمني.
- [ ] تجربة الكل واليوم وآخر 7 أيام والتاريخ المحدد في الأرشيف.
- [ ] حفظ PDF في مجلد فرعي يختاره المستخدم، ثم فتحه والتحقق من اسمه ومحتواه.
- [ ] إلغاء منتقي المجلدات ثم المحاولة مجددًا دون ظهور رسالة حفظ كاذبة.
- [ ] تأكيد أن القفل يظهر عند الرجوع من منتقي المجلدات مع بقاء عملية التصدير سليمة.
- [ ] تشغيل Build Android preview APK يدويًا وفحص نتيجة البناء والتثبيت؛ هذا المسار لم يُنفذ أثناء إعداد الشيفرة.
